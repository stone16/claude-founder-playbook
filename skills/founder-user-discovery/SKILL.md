# Founder User Discovery

## Purpose

Use this skill to design useful customer discovery, synthesize interviews, and translate user evidence into the Idea-stage artifacts that support or block advancement.

## When To Use

Use this skill when a founder needs to decide who to interview, what to ask, how to interpret responses, or how prototype feedback changes the idea. Do not use it for sales scripts, onboarding flows, or post-launch research programs.

## Workflow

1. Define target interview segments by role, pain intensity, buying influence, and current workaround.
2. Write questions that investigate past behavior, stakes, frequency, and existing spend instead of asking for compliments or hypotheticals.
3. After interviews, separate direct observations from founder interpretation.
4. Synthesize patterns, contradictions, and disconfirming evidence across interviews.
5. Capture prototype learnings only as evidence of behavior, comprehension, or willingness to act.

## Artifacts Written

Write or update:

- `idea/customer-discovery-plan.md`
- `idea/interview-synthesis.md`
- `idea/prototype-learnings.md`

Tie every strong claim to the interview or prototype evidence that supports it.

## CLI Verbs Used

This skill does not add CLI behavior. Use implemented validation commands only when helpful:

- `founder status`
- `founder check`
