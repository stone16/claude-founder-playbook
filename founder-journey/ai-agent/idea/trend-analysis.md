# Trend Analysis

## Tailwinds

- **Agent adoption is accelerating**: Gartner projects that by 2028, 33 percent of enterprise software applications will include agentic AI, up from less than 1 percent in 2024. Every new agent team is a potential user of the knowledge base.
- **Framework proliferation creates navigation pain**: The number of agent frameworks grew from roughly 5 in early 2023 to over 50 by mid-2025. More frameworks mean more need for neutral comparison and curation. This trend shows no sign of slowing.
- **Model capability jumps invalidate old knowledge**: Each major model release (Claude 4, GPT-5, Gemini 2.5) changes what architecture patterns are optimal. Content written 6 months ago may recommend patterns that are now obsolete. This creates a continuous demand for fresh, verified content.
- **OpenAI Operator and Claude Computer Use legitimize the category**: When major labs release agent products, enterprise adoption accelerates. Each new agent product launch drives search traffic for "how to build AI agents" and related queries.
- **Rising cost of bad agent architecture**: As more teams deploy agents to production, the cost of architectural mistakes (high latency, runaway costs, prompt injection vulnerabilities) becomes visible. Teams will invest more in getting architecture right the first time.

## Timing Risks

- **Convergence risk**: If the agent framework market consolidates around 2-3 winners, the need for neutral comparison diminishes significantly. Timeline: possible within 12-18 months if a clear standard emerges.
- **AI-generated content flood**: LLMs can already generate reasonable agent architecture advice. As models improve, the marginal value of human-curated knowledge may decrease. Counter-argument: practitioners specifically said they want verified, traceable information, not generated text.
- **Platform absorption**: If cloud providers (AWS, GCP, Azure) build agent knowledge directly into their consoles, they could capture the navigation use case. Mitigation: our value is cross-platform neutrality, which platform-native tools cannot credibly offer.
- **Open-source documentation maturity**: If the major agent frameworks significantly improve their own documentation and comparison guides, they reduce the gap we fill. Current trajectory suggests this is not happening quickly; framework teams are focused on features, not neutral education.

## Evidence

The tailwinds outweigh the risks for the next 18-24 months. The most time-sensitive risk is **convergence**: if we wait 12 months and the market consolidates, the window for a neutral knowledge base may close. The best time to build is now, while fragmentation is at its peak and the need for curation is most acute.
