# Founder Journey Surfaces

Use the three surfaces deliberately so the founder gets both speed and evidence.

## Chat

Use Chat for exploration: sharpening the idea, naming assumptions, preparing interview questions, and unpacking what the founder has learned. Chat is the right place for ambiguous thinking before it is ready to become an artifact.

## Cowork

Use Cowork for shared artifact production. Draft, edit, and tighten the Idea-stage files in `founder-journey/<idea>/idea/`, especially the required `problem-hypothesis.md`, `interview-synthesis.md`, `solution-concept.md`, and `GATE.md`.

## Code

Use Code for deterministic checks. The `founder` CLI validates schemas, required artifacts, evidence links, gate status, and advancement so the decision to move out of Idea is enforced by the harness rather than by memory.
